NoteObservation Model

The data are counts of each species, and we model both presence/absence and counts. We have multiple replicate observations per site, so we assume the counts, \(n_{kj}\) on replicate \(k\) for species \(j\), follow a zero inflated Poisson lognormal distribution with mean \(\lambda_{ij}\) (i.e. constant across replicates within a site). We have a Gaussian overdispersion term for excess variation within a replicate that represents sampling variation. For presences (i.e. to account for zero inflation) we use an occupancy model. ## Downloading and formatting the data

The data are abundances (counts) on each location on a transect. There are 3 islands, each with 3 transects, each with 3 stations. Each station was sampled in 2 seasons, and has 3 replicates.

The steps are: 1. import the data

  1. Format the data for JAGS.
  1. Write the model in JAGS code
  1. Run the JAGS code

We get some output, which we will use to estimate our diversity statistics

# Function to convert vector of data to matrix

# vec: vector of values, should have names. 
# varname: name of variable to extract
# RowsFirstIndex: Should the first index be for rows or columns?
# sortNumeric: Should the indices be converted to integer and then sorted? Warning: make sure they are integers!

# Details
# For the variable of interest the name should be of the format "varname[i,j]" 
#  where i and j are the row and column names (in either order). 
#  They will probably be integers.
VecToMatrix <- function(vec, varname, RowsFirstIndex=TRUE, sortNumeric=TRUE) {
  # extract variable and indices
  variable <- vec[grep(paste0("^", varname, "\\["), names(vec))]
  Index1 <- gsub(",.*", "", gsub(".*\\[", "", names(variable)))
  Index2 <- gsub("\\]", "", gsub(".*,", "", names(variable)))

# create matrix with row and column names 
  mat <- matrix(NA, nrow=length(unique(Index1)), ncol=length(unique(Index2)),
                dimnames=list(unique(Index1), unique(Index2)))
# fill in entries
  for(i in seq_along(variable))  mat[Index1[i], Index2[i]] <- variable[i]
# If the column name is the first index, transpose the matrix
  if(!RowsFirstIndex) mat <- t(mat)
# Sort the rows and columns, if requested
  if(sortNumeric) {
    mat2 <- mat[sort(as.numeric(rownames(mat))), 
                sort(as.numeric(colnames(mat)))]
  }
  return(mat)
}


MatrixToArray <- function(mat, varname, RowsSecondIndex=TRUE, sortNumeric=TRUE) {
  # extract variable and indices
  variable <- mat[,grep(paste0("^", varname, "\\["), colnames(mat))]
  Index1 <- gsub(",.*", "", gsub(".*\\[", "", colnames(variable)))
  Index2 <- gsub("\\]", "", gsub(".*,", "", colnames(variable)))

# create matrix with row and column names 
  arr <- array(NA, 
               dim =c(nrow(mat), length(unique(Index1)), length(unique(Index2))),
               dimnames=list(rownames(mat), unique(Index1), unique(Index2)))
# fill in entries
  for(i in seq_along(variable[1,]))  arr[,Index1[i], Index2[i]] <- variable[,i]
# If the column name is the first index, transpose the matrix
  if(!RowsSecondIndex) arr <- aperm(1,3,2)
# Sort the rows and columns, if requested
  if(sortNumeric) {
    arr <- arr[,sort(as.numeric(dimnames(arr)[[2]])), 
                sort(as.numeric(dimnames(arr)[[3]]))]
  }
  return(arr)
}



# this is a function to calculate the summaries we want
CalcSumm <- function(mc, ...) {
  require(coda)
  require(MCMCglmm)
  Summ <- summary(mc)
  Summ$HPD <- HPDinterval(mc, prob=0.95)
  Summ$PMode <- posterior.mode(mc, ...)
  Summ
}

# Calculate summary stats from array: keep as mcmc object
CalcSummaryFromArray <- function(arr, FUN=mean, mcmc=FALSE, centre=TRUE) {
  Grand <- apply(arr, "Iteration", FUN, na.rm=TRUE)
  Sp <- apply(arr, c("Iteration", "Species"), FUN, na.rm=TRUE)
  colnames(Sp) <- paste0("Species", colnames(Sp))
  Site <- apply(arr, c("Iteration", "Site"), FUN, na.rm=TRUE)
  colnames(Site) <- paste0("Site", colnames(Site))
  if(centre) {
    Sp <- sweep(Sp, 1, Grand, "-")
    Site <- sweep(Site, 1, Grand, "-")
  }
  res <- cbind(Grand, Sp, Site)
  if(mcmc) res <- coda::as.mcmc(res)
  res
}

# Calculate correlation between statistics in two data sets 
#   (err, that could be explained better)
CalcCorr <- function(mcmc1, mcmc2, Name) {
  if(nrow(mcmc1)!=nrow(mcmc2)) stop("mcmc1 & mcmc2 must have same number of rows")
  Use1 <- colnames(mcmc1)[grep(Name, colnames(mcmc1))]
  Use2 <- colnames(mcmc2)[grep(Name, colnames(mcmc2))]
  if(any(Use1%notin%Use2) | any(Use2%notin%Use1)) stop(paste0("mcmc1 and mcmc2 should have same variables for ", Name))
  
  Cor <-   sapply(1:nrow(mcmc1), function(i, mc1, mc2) {
    cor(mc1[i,], mc2[i,])
  }, mc1 = mcmc1[,Use1], mc2 = mcmc2[,Use2])  
  Cor
}


# Function to plot parameters
PlotPars <- function(Summ, At="Orig", use=NULL, ave=NULL, Xlim=NULL, ...) {
  if(is.null(use)) use <- 1:length(Summ$PMode)
  if(length(At)==length(use)) {
    At.y <- At
  } else {
    At.y <- switch(At, 
                   Orig = 1:use, 
                   rank = rank(Summ$PMode[use], ties="random")
    )
  }
  if(is.null(Xlim)) Xlim=range(Summ$HPD[use,])
  plot(Summ$PMode[use], At.y, xlim=Xlim, type="n", ...)
  if(!is.null(ave)) {
  rect(Summ$HPD[ave,"lower"], -5, Summ$HPD[ave,"upper"], 2*max(At.y), border = NA, col="pink")
  abline(v=Summ$PMode[ave], col=2)
    
  }
  points(Summ$PMode[use], At.y, ...)
  segments(Summ$HPD[use,"lower"], At.y, Summ$HPD[use,"upper"], At.y)
  
}

\(\alpha\)-var-diversity: Unevenness

Unevenness for each site is \(U_j = \text{Var}_i(k_{i,j})\), i.e. the variance in the species’ effects on each site. For abundance this is related to measures such as Shannon’s and Simpson’s diversity: the more evenly distributed species’ abundances are, the higher the diversity (an uneven distribution would mean one or a few species with high abundances, i.e. dominating the community). Our variance is a measure of unevenness: when it is zero, all species have the same abundance, so there is maximal diversity.

Gamma Diversity and its decomposition

The statistics presented above are site or species specific. We can look at overall diversity by looking across sites, to get (reading from Erik’s figure)

\[ \begin{aligned} \sigma^2_\gamma &= \sigma^2_\alpha + \sigma^2_\delta + \sigma^2_\beta \\ &= R + D \\ \sigma^2_\gamma &= \sigma^2_\beta + \sigma^2_\delta + \sigma^2_\alpha \\ &= U + N \end{aligned} \]

where

  • \(R = \sigma^2_\alpha + \sigma^2_\delta = \bar{P}_j\) is replacement
  • \(D = \sigma^2_\beta = \text{Var}(O_{j})\) is disparity. Variance over species in mean prevalence etc.
  • \(U = \sigma^2_\beta + \sigma^2_\delta = \bar{U}_i\) is mean unevenness
  • \(N = \sigma^2_\alpha = \text{Var}(S_{i})\): is nestedness. Variance over sites in mean prevalence, species richness

CalcGammaStats <- function(arr) {
  GammaStats <- cbind(U = apply(apply(arr, c("Iteration", "Site"), sd, na.rm=TRUE)^2, 
                                "Iteration", mean, na.rm=TRUE)^2,
                      R = apply(apply(arr, c("Iteration", "Species"), sd, na.rm=TRUE)^2, 
                                "Iteration", mean, na.rm=TRUE)^2,
                      N = apply(apply(arr, c("Iteration", "Site"), mean, na.rm=TRUE), 
                                "Iteration", sd, na.rm=TRUE)^2,
                      D = apply(apply(arr, c("Iteration", "Species"), mean, na.rm=TRUE), 
                                "Iteration", sd, na.rm=TRUE)^2)
  colnames(GammaStats) <- c("U", "R", "N", "D")
  GammaStats <- cbind(GammaStats, 
                      PropN = GammaStats[,"N"]/(GammaStats[,"U"]+GammaStats[,"N"]),
                      PropD = GammaStats[,"D"]/(GammaStats[,"D"]+GammaStats[,"R"]))
  GammaStats
  
}

From the plot we can see that nestedness is low, so most variation is across sites is because of turnover, rather than changes in total numbers of species or numbers of individuals. In contrast, disparity is high across species, especially abundance, so variation between species in global occupancy and abundance (i.e. some are rare and others common) is driving diversity in these communities, rather than species having similar overall abundances but segregating between sites.
